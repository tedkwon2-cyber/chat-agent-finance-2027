과금 단위: AI가 실제 응답한 상담 참여 1건. 최초 AI 응답부터 사람 상담 전환 또는 24시간 무응답까지를 1회로 정의하는 안입니다. 동일 참여의 여러 메시지는 중복 과금하지 않으며, 테스트·오류·무응답은 제외합니다. 이는 우리 상품 정책 제안으로, 출시 전에 계측과 약관을 확정해야 합니다.

매출 계산: 기본 구독 + max(월 AI 참여 − 포함량, 0) × 초과 단가. 파트너별 포함량은 월별 소멸하며 이월하지 않는 안입니다. 전환·해지 월에는 일할 계산을 적용한다고 가정합니다.

비용 통제: 파트너별 월 예산 상한, 80%·100% 사용 알림, 초과 전 동의, 반복 호출 제한을 적용합니다. 무료 체험·테스트 채널 수는 아직 산정하지 않았습니다. 본 계산의 비용 대상은 유료 모델 사용 채널이며, 무료 사용 채널이 생기면 그 모델 사용료를 별도로 더해야 합니다.

별도 사업: 메시지·전화 발송료, 외부 채널 이용료, 맞춤 구축 매출은 미포함입니다. 현재 제공 중인 무료·유료 상품이 있다면 잠식 매출과 추가 원가를 합산해 다시 평가해야 합니다.

9월 말 일반 750채널, 헤비 1,000채널. 7월 25% → 8월 60% → 9월 100%의 가입 경로입니다. 3Q 매출 5.91억 원, 모델 사용료 2,363만 원을 점검합니다.

산출물: 유료 채널 · 매출 · 모델 사용료

전환 목표의 실행 규모

  • 3Q 신규 유료 유입 (이탈 보충 포함)1,780개
  • 필요 헤비 활성 체험 (40% 전환 가정)2,500개
  • 필요 일반 활성 체험 (25% 전환 가정)3,000개

체험→유료 전환율은 실행 계획용 가정입니다. 인력 수·온보딩 비용·고객 확보비는 이번 비용 계산에 반영하지 않습니다.

관리 지표의 범위

  • 매출: 유료 전환, 구독료, 실제 상담량, 평균 할인율을 검증합니다.
  • 모델 사용료: 월별 사용 채널 수와 채널당 모델 사용료를 추적합니다.
  • 비용 대상: 무료·테스트·복수 채널이 추가되면 별도 수량을 확인합니다.
  • 해석: 다른 운영 비용이 미산정이므로 이익이나 사업 흑자 시점은 판단하지 않습니다.

9월로 출시가 늦어진다면

현재 7월 출시안과 동일한 9월 말 고객 목표를 유지할 경우, 3Q 예상 매출은 2.19억 원, 모델 사용료는 875만 원, 모델 사용료 차감 후 금액은 2.10억 원입니다. 9월 한 달에 가입이 집중되는 실행 부담은 별도로 판단해야 합니다.

07 / ASSUMPTIONS & AUDIT TRAIL

사용자 제공 기준과 매출 가정을 구분한다

구분입력 · 근거계획에 적용한 방식
사용자 제공전체 타겟 20,000개, 헤비 5,000개, 2027년 3Q 목표일반 15,000개로 차감. 타겟을 유료 확정 고객으로 간주하지 않음.
사용자 제공채널당 월 모델 사용료 약 10,000원이번 계획에 반영하는 유일한 비용 항목. 일반·헤비 동일 단가.
비용 범위임베딩·내부 모델·인건비·인프라·마케팅 등은 산정에서 제외미산정 비용을 0원으로 간주하거나 운영손익·필요자금을 계산하지 않음.
외부 확인채널톡 공식 가격기본 구독 + AI 참여량 과금 구조 참고. 자사 가격은 자체 제안.
환산 가정유료 파트너 1개 = 모델 사용 채널 1개, 월중 가입·해지 일할 반영기간 비용 = 월평균 유료 채널 수 × 월 모델 사용료. 무료·테스트 채널은 모수 미확정으로 제외.
사업 가정기존 파트너 대상 판매, 7월 출시, 기초 유료 채널 0개기존 매출 가정 유지. 출시 월은 시뮬레이터에서 조정 가능.
사업 가정전환율·상담량·할인율·이탈률실측 데이터 없음. 파일럿 결과로 교체해야 함. 이탈률은 목표 달성에 필요한 신규 유입 수에 반영.
내부 확인 범위기존 조사에서 rocket-mcp로 채팅·AI 상담 통계 경로 우선 탐색실제 파트너 수·사용량·유료 전환율은 조회·확정하지 않음.
핵심 계산식 · 범위

유료 채널: 9월 말 일반 = 15,000 × 일반 전환율, 헤비 = 5,000 × 헤비 전환율. 유료 파트너 1개당 모델 사용 채널 1개를 가정합니다. 신규 유입 = 기말 − 기초 × (1 − 월 이탈률).

가입 경로: 7월·8월·9월 기말 채널은 9월 목표의 25%·60%·100%. 4Q는 9월 목표에서 12월 배수까지 선형 확대. 8·9월 출시를 선택하면 9월 목표는 유지하고 남은 출시 월에 가입을 압축합니다. 각 타겟 모수를 초과하지 않습니다.

기간 매출: 월평균 유료 채널 = (기초 + 기말) / 2. 구간별 평균 채널 × [구독료 + max(가정 상담량 − 포함량, 0) × 초과 단가] × (1 − 할인율). 구간별 월 상담량은 동일하고 월중 가입·해지는 균등 발생한다고 가정합니다.

모델 사용료: 월평균 모델 사용 채널 × 채널당 월 모델 사용료. 기준 단가 10,000원. 일반·헤비 동일하며 상담 참여 건수·토큰 수에 비례해 재계산하지 않습니다. 미사용·무료 체험 채널의 별도 비용은 미산정입니다.

차감 후 금액: 매출 − 모델 사용료. 다른 비용이 빠진 중간 계산값입니다. 매출총이익·공헌이익·운영이익·EBITDA·순이익·현금 흐름을 의미하지 않습니다.

월말 환산과 기간 합계: 9월 말 월매출·모델 사용료 환산은 기말 채널을 한 달 내내 유지한다고 가정합니다. 3Q 및 연간 금액은 각 월평균 채널로 계산한 값을 합산합니다. 둘을 섞어서 비교하지 않습니다.

산정 제외: 임베딩 및 내부 모델 운영, 인건비, 공통 인프라, 저장·검색·관측 비용, 고객 확보·온보딩, 결제·회수 손실, 구축·파일럿, 세금·감가상각·이자. 이들 비용은 미확정이므로 금액 가정을 두지 않습니다. 운영손익·흑자 전환·손익분기점·필요자금·투자 회수기간도 산정하지 않습니다.
